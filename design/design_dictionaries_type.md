# JavaScript風オブジェクトリテラルの解釈

TypeScriptライク＝JavaScriptライクを目指すうえで実装は必須。
ただし、これを実際のオブジェクトを定義するための構文とするとプロトタイプベース排除を目指した言語コンセプトと矛盾する可能性がある

1. { key: value }は匿名構造体(値型)として扱う  
   プロパティの追加・変更・削除は行わない  
   スプレッド構文に対応する。キーの重複は後ろのキーが優先  
   関数もvalueとして持てるが動的書き換え禁止
2. { "key": value }をディクショナリ型(型そのものの詳細は別途検討)として扱う  
   ブラケット記法、ドット記法どちらでプロパティの追加・値の更新ができ、アクセスも可能
   削除はdelete演算子で行う  
   →つまりこちらがJavaScriptに近い機能ということ
